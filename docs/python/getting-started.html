Getting started with Python

Use a Linux development checkout with the repository's native build prerequisites and Python 3. The Python package is a development interface in python/ams_mel; there is no wheel or PyPI release. The native bridge and the runtime provider are separate shared libraries.

Build and load the facade

Run these commands from the repository root. make native builds the production facade without installing or loading a runtime MEL provider.

make native
export PYTHONPATH="$PWD/python${PYTHONPATH:+:$PYTHONPATH}"
export AMS_MEL_NATIVE_LIB="$PWD/native/build/lib/libams_mel_c.so.0"
python3 -c 'from ams_mel.common import abi_version; print(abi_version())'

AMS_MEL_NATIVE_LIB must be the absolute full path to libams_mel_c.so.0 or libams_mel_c.so, set before the first import. Import loads this library and binds the required symbols. It does not create a Session, attach a channel or invoke a provider factory. This applies to all three public modules, including ams_mel.common, because Python initializes the parent package first. A missing or relative environment value raises ImportError; loader or symbol errors can also prevent import. Use a facade built from the matching checkout.

{{api:abi_version}} reports the loaded facade's {{api:AbiVersion}}. It is distinct from the provider's {{api:ProviderVersion}}, which requires an open session.

Inspect a provider

Supply a compatible provider-library path and its documented instance and aperture values. The bridge does not invent a configuration grammar or default sensor identity. This function returns owned results that remain usable after its session closes.

from ams_mel.ir import Session


def inspect_provider(provider_library, instance, aperture):
    with Session.open(provider_library, instance, aperture) as session:
        version = session.provider_version()
        advertised = session.capabilities()
        return version, advertised

{{api:Session.capabilities}} preserves provider order and all capability fields, nested bands and strings. An empty list or an unconfigured advertisement is valid. Choose a suitable channel using the provider contract and the advertised types; discovery itself neither attaches nor enables it and does not prove that hardware is ready.

{{api:Session.open}} accepts max_async_requests as a keyword-only admission limit. The default 0 means unlimited. A positive limit can reject a new request with ErrorKind.RESOURCE_EXHAUSTED; it does not create a Python retry queue. Request completion and closure are described in ownership and errors.

Choose attachment values

Channel factories accept immutable configuration records. {{api:UciId}} contains exactly 16 UUID bytes and a descriptive label. {{api:ComponentLocation}} carries location offsets in metres plus provider-defined key and system-name strings. Configuration construction performs input validation; opening a channel is the separate operation that contacts the provider.

ImageConfig additionally supplies positive buffer_count, buffer_size and queue_capacity. Its defaults are convenience values, not a guarantee that the provider's frame layout will fit. Control-only Image and StackedImage configurations contain no acquisition geometry or buffer sizing.

Receive one owned frame

After choosing a provider and a valid Mono8 acquisition configuration, pass them into this function. Entering the stream context does not start acquisition; start() is explicit. The function returns copied pixel bytes and metadata, with no remaining dependency on its native owners.

from ams_mel.ir import ImageConfig, Session


def receive_one_frame(provider_library, instance, aperture,
                      config: ImageConfig):
    with Session.open(provider_library, instance, aperture) as session:
        with session.open_image_stream(config) as image:
            image.start()
            return image.receive(timeout_ms=1000)

{{api:ImageStream.receive}} returns a {{api:Frame}} with tightly packed, single-band, 8-bit monochrome pixels: bytes. The call can raise a timeout if no frame arrives. A timeout is an observation outcome; it does not cancel native work. This function's context exit still closes its local stream.

For metadata registration before Start, control-only Image, complete C2 commands and navigation input, continue to IR workflows. For RF Admin, use its independent factory instead of a Session.
