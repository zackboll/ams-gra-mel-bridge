“Used in” means a source-level reference in a canonical main or its listed support sources, with mock-backed execution within the documented contract. It does not establish full provider or hardware support. Repeated uses within one example are listed once. Required, conditional and represented-only

Core lifecycles and supported required command paths are implemented within their documented slices. Conditional families require runtime provider support: an interface existing in this reference does not force a provider to supply it. Capability enums preserve upstream vocabulary, including types without a corresponding bridge operation. Consult IR Workflows and RF Workflows before interpreting them.

The alias AMS.MEL.IR.Health_Status.Metadata.Status renames AMS.MEL.Status. GNATdoc omits this one source-visible package-renaming section; the target is linked above. It is a source-visible alias rather than another public library unit. The current-build reports record its renderer exception separately from documentation gaps.
